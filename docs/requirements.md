# CampusCare – Requirements

## Project Goal
CampusCare is a platform for managing college events, volunteering, welfare activities, student participation, and communication.

## User Roles
- Student
- Organizer
- Administrator

## MVP Features
1. User registration and login
2. Role-based access control
3. Create, edit, and view events
4. Student event registration and cancellation
5. Event capacity and waitlist
6. Schedule conflict detection
7. Volunteer registration and task assignment
8. Event attendance
9. Feedback collection
10. Admin dashboard

## Future Features
- Temporary event chat
- Notifications
- Points and badges
- Certificates
- Environmental activity tracking
- Analytics and recommendations
